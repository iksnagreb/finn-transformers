    Eigen ist eine C++ Header-Only-Bibliothek für lineare Algebra (Matrizen, Vektoren, numerische Berechnungen). ORT nutzt sie intern für mathematische Operationen.

Warum der Fehler?

ORT versucht Eigen automatisch von GitLab herunterzuladen (FetchContent). Der Download schlägt fehl weil:

Die heruntergeladene Datei hat einen anderen SHA1-Hash als erwartet
Das passiert wenn GitLab ein dynamisch generiertes ZIP liefert dessen Inhalt sich minimal unterscheidet (z.B. Timestamps) — ein bekanntes Problem mit GitLab-Archive-URLs
Die Lösung (--use_preinstalled_eigen) sagt ORT: "Lad nichts herunter, nutz stattdessen das bereits installierte Eigen aus dem System" (eigen3). Das umgeht den fehlgeschlagenen Download komplett.



./build.sh \
  --config Release \
  --use_cuda \
  --cuda_home /usr/local/cuda \
  --cudnn_home /usr \
  --build_wheel \
  --skip_tests \
  --parallel 4 \
  --use_preinstalled_eigen \
  --eigen_path /usr/include/eigen3 \
  --cmake_extra_defines \
      CMAKE_CUDA_ARCHITECTURES=87 \
      Python_EXECUTABLE=/usr/bin/python3.10 \
      CUDNN_LIBRARY=/usr/lib/aarch64-linux-gnu/libcudnn.so
