tmux, am einfachsten:


tmux new -s repro
cd language && RUN_VIA_SLURM=1 dvc repro 2>&1 | tee repro.log
# Ctrl+B, dann D zum Abkoppeln; danach kannst du VS Code schließen
tmux attach -t repro   # später wieder einhängen
tmux läuft unabhängig von VS Code und SSH weiter. Merk dir den Login-Node, z. B. mit hostname, denn du musst beim Wiederverbinden auf demselben landen.
